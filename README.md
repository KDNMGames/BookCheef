# Book Gallery — расширенная версия

Публичная книжная витрина + защищённая админ-панель. В этой версии добавлены:
- категории книг;
- поиск по названию, описанию и категории;
- фильтры по категориям;
- избранное (сохраняется в браузере читателя);
- отдельная страница книги `/book/ID`;
- счётчик просмотров и статистика в админке;
- прежние функции: 3D-карточки, свечение последней добавленной книги, фон, логотип, цвета, контакты, соцсети, загрузка изображений.

## Подключение Supabase
1. Создай проект на https://supabase.com/dashboard
2. В SQL Editor выполни целиком `supabase/schema.sql`.
3. Authentication → Users → Add user: создай аккаунт администратора.
4. Скопируй UUID пользователя и выполни в SQL Editor:
   `insert into public.admins(user_id) values ('UUID-ПОЛЬЗОВАТЕЛЯ');`
5. Project Settings → API: скопируй Project URL и anon/publishable public key. Не используй service_role/secret key.
6. Скопируй `.env.example` в `.env` и заполни URL и публичный ключ.

## Запуск
Установи Node.js LTS с https://nodejs.org/, распакуй архив, открой терминал в папке проекта:
```bash
npm install
npm run dev
```
Открой локальный URL, который покажет Vite. Админка: `/admin`.

## Бесплатная публикация
1. Перед сборкой заполни `.env`.
2. Выполни `npm run build`.
3. Создай аккаунт на https://dash.cloudflare.com/
4. Workers & Pages → Create → Pages → Direct Upload.
5. Загрузи содержимое папки `dist`.
6. Сайт будет доступен по адресу `https://имя-проекта.pages.dev`; админка — `/admin`.

Vite SPA fallback для Cloudflare Pages включён файлом `public/_redirects`, поэтому прямое открытие `/admin` и `/book/ID` будет работать.
При обновлении кода пересобери `dist` и загрузи новую версию. `.env` должен быть заполнен до сборки.

## Как добавлять книги
Войди на `/admin`, заполни название, категорию, описание, обложку и ссылку покупки. Новая книга автоматически будет первой и получит свечение. Категории формируются из введённых значений. Статистика просмотров обновляется при открытии страницы книги; избранное каждого читателя хранится локально в его браузере.

## Бесплатные тарифы и безопасность
Supabase Free и Cloudflare Pages Free имеют лимиты и условия, которые могут меняться. Проверь:
- https://supabase.com/pricing
- https://developers.cloudflare.com/pages/platform/limits/
Не публикуй service_role/secret key. Публичный anon/publishable key предназначен для браузера и защищён политиками RLS. Используй длинный уникальный пароль администратора.
