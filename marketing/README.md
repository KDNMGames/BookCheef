# BookCheef — система бесплатного продвижения

Цель: привлекать читателей на сайт https://kdnmgames.github.io/BookCheef/ и подписчиков в Telegram https://t.me/BookCheef без рекламного бюджета.

## Принцип безопасности

Автопубликация разрешена только для собственных площадок BookCheef или внешних площадок, где одновременно:
1. действующие правила явно разрешают саморекламу/продвижение проекта;
2. правила явно разрешают автоматическую публикацию либо официальный API/бот прямо предусмотрен для этой цели;
3. соблюдены лимиты, требования к маркировке и частоте.

Если разрешена реклама, но не автоматизация, публикация остаётся ручной. Если правила неоднозначны — статус `review_required`. Никаких личных рассылок незнакомым людям, массовых комментариев, обхода капчи, парсинга закрытых групп, фейковых аккаунтов и повторяющегося спама.

## Внедрённые компоненты

- `platforms.json` — реестр площадок, статус правил, режим размещения и ссылки на первоисточники.
- `campaigns.json` — журнал кампаний и публикаций.
- `../scripts/build-promo-pack.mjs` — генератор уникальных рекламных текстов и UTM-ссылок.
- `generated/current-campaign.md` — готовый стартовый набор текстов.

## Первый набор материалов

1. Представление BookCheef: библиотека книг и интерактивных историй.
2. Подборка бесплатных книг.
3. Интерактивная литература: читатель влияет на сюжет.
4. Новинки недели с прямыми ссылками на книги.

Для каждой внешней площадки создаётся отдельный текст. Нельзя просто копировать один и тот же рекламный комментарий во множество сообществ.

## Процесс

1. Найти тематическую площадку и её официальные правила.
2. Зафиксировать URL правил, дату проверки, допустимые форматы и разрешение на автоматизацию.
3. Только статус `auto_allowed` допускает автоматическое размещение.
4. Статусы `manual_only`, `review_required`, `blocked` запрещают автоматическую публикацию.
5. После публикации записать URL, дату, формат и результат в журнал.
6. Если правила изменились, публикация останавливается до повторной проверки.

## Приоритетные темы для поиска

- чтение бесплатных книг и электронные библиотеки;
- фантастика, фэнтези, научная фантастика;
- интерактивные книги и текстовые игры;
- детская литература и сказки;
- авторы, самиздат и литературные сообщества.

## Измерение результата

Использовать UTM-метки для переходов на сайт. Сравнивать источники по посещениям и вовлечению. Не считать просмотры поста подписчиками и не считать переходы регистрациями. Telegram-переходы пока учитывать отдельно по опубликованным ссылкам и доступной статистике канала.

## Изменение статуса площадки

Никогда не повышать площадку до `auto_allowed` по догадке. Нужны прямая ссылка на правила и явное разрешение именно на автоматическую публикацию/официальный API.
