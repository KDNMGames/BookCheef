# BookCheef Telegram Mini App

## Что это
Мобильная панель управления ботом BookCheef, открываемая из Telegram через кнопку меню или кнопку в сообщении /start.

URL: https://kdnmgames.github.io/BookCheef/tg-app/

## Возможности
- Состояние генератора: включён / остановлен.
- Текущая книга: этап, число завершённых глав, примерный объём текста, число сохранённых изображений, время последнего обновления.
- История последних запросов.
- Отчёт о доступности провайдеров и бесплатной квоте, если провайдер сообщил эти данные.
- Для администратора: создать одну книгу по теме, запустить и остановить генератор.
- Автообновление панели каждые 20 секунд и ручная кнопка обновления.
- Уведомления о состоянии и ошибках также остаются в Telegram-чате.

## Архитектура и безопасность
- Статика: `tg-app/index.html`, GitHub Pages.
- API: Supabase Edge Function `bookcheef-tg-app-api`.
- Telegram Mini App `initData` проверяется на сервере по HMAC-SHA256 с Bot Token и ограничением срока действия 24 часа. Данные из `initDataUnsafe` не используются для авторизации.
- API читает и изменяет данные через service role только после проверки подписи Telegram и списка разрешённых пользователей.
- Создание книги передаётся внутреннему действию `create_book_request` функции `telegram-bot`; генератор продолжает использовать существующий free-only preflight и worker.
- Управление генератором доступно только Telegram ID из `TELEGRAM_ADMIN_IDS`.
- Платные провайдеры и платные fallback не вызываются. Кнопка «Запустить» только включает флаг генератора; она не обходит проверку бесплатной квоты.
- Кнопки и подписи показывают смысл действия до нажатия; полная очистка очереди в Mini App не добавлена, чтобы исключить случайное удаление данных.

## Развёртывание
- `telegram-bot`: версия 40, ACTIVE.
- `bookcheef-tg-app-api`: версия 1, ACTIVE, `verify_jwt=false` (проверяется Telegram initData внутри функции).
- GitHub Pages: `/BookCheef/tg-app/`.

## Первый запуск
1. Открыть чат с ботом и отправить `/start`.
2. Нажать «📊 Открыть BookCheef App» или кнопку меню «BookCheef».
3. Панель запросит статус. Если Telegram сообщает, что сессия отсутствует, закрыть приложение и открыть его именно из чата с ботом.
4. Администратор может создать книгу, запустить или остановить генератор. Остальные разрешённые пользователи видят только доступную им информацию.

## Проверка
Развёртывание Edge Functions подтверждено Supabase: обе функции ACTIVE. Полный интерактивный прогон от имени Telegram-пользователя не выполнялся, поскольку для него нужен реальный запуск Mini App в Telegram с подписанным initData. Перед первым созданием книги рекомендуется открыть приложение и проверить успешную загрузку панели.
